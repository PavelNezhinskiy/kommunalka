# Коммуналка

Учёт электричества, воды и отопления: показания счётчиков, тарифы с историей изменений,
авансы и годовые расчёты (Nebenkostenabrechnung).

Одностраничное приложение без сборки. Данные — в Supabase, хостинг — Vercel, устанавливается
на телефон как PWA.

## Структура

| Файл | Назначение |
|---|---|
| `index.html` | всё приложение: разметка, стили, логика, расчёты |
| `sw.js` | service worker — кэш оболочки, работа без сети |
| `manifest.webmanifest` | манифест PWA (имя, иконки, standalone) |
| `vercel.json` | заголовки и rewrites; статика отдаётся напрямую, остальное → `index.html` |
| `icon-*.png` | иконки для домашнего экрана |

## Локальный запуск

Нужен http-сервер — service worker и манифест не работают с `file://`:

```bash
npx serve .
# или
python -m http.server 8000
```

## Деплой

Проект подключён к Vercel. При деплое из гита — пуш в `main`.
Вручную: `npx vercel --prod`.

После деплоя проверить, что отдаются файлами, а не HTML:

- `/manifest.webmanifest`
- `/sw.js`

## Данные

Supabase, таблицы: `readings`, `tariffs`, `advances`, `settlements`, `settings`.
URL и publishable-ключ зашиты в `index.html` — это клиентский ключ, он виден любому
посетителю сайта. Доступ к данным должен ограничиваться **RLS-политиками** в Supabase,
а не секретностью ключа.

## Установка на телефон

Открыть сайт → меню браузера → «Добавить на экран «Домой»» (iOS Safari) либо
«Установить приложение» (Android Chrome).

## Единицы отопления

Показания комнатных распределителей умножаются на коэффициент комнаты:

| Комната | Коэффициент |
|---|---|
| Ванная | 0.942 |
| Кухня | 1.314 |
| Спальная | 2.052 |
| Детская | 1.314 |
| Зал | 3.502 |

Комнаты вносятся независимо друг от друга — можно снять показание только одной.
